# بطاقة دعوة زفاف ملكية تفاعلية | Royal Wedding Invitation

تصميم عصري وفاخر لبطاقة دعوة زفاف رقمية وتفاعلية باللغة العربية مع مؤثرات بصرية وصوتية راقية.

## ✨ المميزات
- **تصميم ملكي فاخر (Gardenia Night & Gold)** متناسق مع شاشات الهواتف وجميع الأجهزة.
- **تأثيرات حركية فاخرة (Motion & Shimmer):** أزرار براقة وتدرجات ضوئية تفاعلية.
- **مشغل موسيقى هادئة** في الخلفية مع زر تحكم أنيق.
- **بطاقات قصص متتابعة (Story Carousel)** ومحاور تفاعلية.
- **تأكيد الحضور (RSVP)** وموقع القاعة وتفاصيل الحفل.
- **جاهز للنشر المباشر** على Vercel أو أي منصة استضافة ثابتة.

## 🚀 النشر على Vercel
1. استيراد المستودع من Vercel.
2. الضغط على **Deploy** دون الحاجة لأي إعدادات إضافية (Zero Config).
